# Приложение для подбора вин

Python 3.12

## Запуск

Я сижу на Fedora OS, команды соответствующие
```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Для модели используется st.cache_resource, чтобы загрузить ее один раз и дальше использовать тот же объект при перезапусках приложения

Для таблиц используется st.cache_data т.к. он сохраняет данные и возвращает их копию, поэтому изменения таблицы не затронут сохраненный результат

Если вызвать joblib.load без декоратора, модель будет заново загружаться при каждом действии пользователя, что очевидно не должно так работать
